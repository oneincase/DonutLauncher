# 甜甜圈控制台改进路线图

## 目标

保持纯甜甜圈体验，强化搜索、键盘导航、稳定性与可测试性。本期不打包发布，继续留在 Electron。

## 已完成

**布局与交互**
- 顶部搜索框，输入实时过滤，无结果显示空态
- 方向键/WASD 移动选择，Enter 启动，Esc 隐藏
- 环形图标悬停显示收藏星标，收藏/最近使用/名称排序可切换

**扫描与图标**
- `icns-lib` 解析异步化，图标加入磁盘缓存（按应用路径 + icns mtime 校验）
- `getFileIcon` 保留为无 icns 时的兜底

**设置与数据**
- 新增旋转速度、搜索框开关、排序方式、排除应用、收藏列表、最近使用记录
- 主进程在启动应用时记录 `recentUsage`
- 快捷键注册失败时在设置面板提示
- 设置面板按“启动 / 外观 / 应用”分组重排

**体验**
- 唤出窗口按鼠标所在屏幕定位，支持多显示器
- 移除模糊滤镜，避免透明窗口残影

**布局取舍**
- 试做网格/列表备选布局后按使用反馈移除，保持纯甜甜圈形态，控制界面复杂度

**测试与工具**
- 环形布局边界、搜索/排序、settings schema、icns 解析单元测试
- `tools/verify-screenshot.js` 截图验证环形布局
- 主进程日志文件与未捕获异常记录

## 待办

- 打包发布（DMG、签名公证）
- 更完整的端到端自动化测试
